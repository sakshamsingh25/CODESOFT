# Machine Learning Internship - CodSoft (Batch B94)

This repository contains the projects developed during my Machine Learning internship at **CodSoft** (April-May 2026). The internship focused on building practical, scalable AI models using Python and popular data science libraries.

## 🚀 Project Overview

### 1. Movie Genre Classification
* **Objective:** Predict the genre of a movie based on its plot summary.
* **Tech Stack:** Python, Scikit-learn, NLP (TF-IDF).
* **Key Insight:** Utilized LinearSVC to handle high-dimensional text data efficiently.

### 2. Credit Card Fraud Detection
* **Objective:** Build a model to identify fraudulent credit card transactions.
* **Tech Stack:** Pandas, Scikit-learn (Random Forest/Logistic Regression).
* **Status:** Successfully handled highly imbalanced datasets to ensure high recall for fraud cases.

### 3. Customer Churn Prediction
* **Objective:** Predict whether a customer will leave a service based on historical behavior.
* **Tech Stack:** XGBoost, Pandas.
* **Outcome:** Analyzed key features like geography and age to identify churn risk.

### 4. Spam Email Detection
* **Objective:** Categorize emails as 'Spam' or 'Ham' (Legitimate).
* **Tech Stack:** Natural Language Processing (NLP), Naive Bayes.
* **Key Insight:** Implemented a CountVectorizer pipeline for real-time classification.

### 5. Handwritten Digit Recognition
* **Objective:** Classify images of handwritten digits (0-9) using the MNIST dataset.
* **Tech Stack:** TensorFlow, Keras, Neural Networks.
* **Result:** Achieved a final model accuracy of **97.00%**.
